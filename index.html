Run an Arca Node

Follow our unified documentation guide to easily install and fast-sync an Arca network core validator binary block parameter instance.

Minimum VPS System Specifications

  • OS: Ubuntu Linux 22.04 LTS
  • CPU: 4 Cores (vCPU) or higher
  • RAM: 16 GB DDR4/DDR5 ECC
  • Storage: 500 GB NVMe M.2 SSD
install_node.sh 
# Step 1: Update Linux Packages
sudo apt update && sudo apt upgrade -y

# Step 2: Install Development Toolkits
sudo apt install curl build-essential git jq snapd -y

# Step 3: Fetch & Install Core Arca Binary Compiler
curl -sL https://get.arca.network/installer.sh | bash

# Step 4: Initialize Network Moniker Environment
arcanode init --moniker "YourNodeName" --chain-id arca-mainnet-1

# Step 5: Start Validator System Service Node daemon
sudo systemctl enable arcanode && sudo systemctl start arcanode
echo "Arca Node status successfully loaded! Syncing chain..."
